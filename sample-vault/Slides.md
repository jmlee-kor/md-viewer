# md-viewer

**폐쇄망에서 그대로 도는** Obsidian형 마크다운 뷰어

<!-- 발표자 노트: 이 줄은 발표자 뷰(P)에만 보입니다. 청중 창에는 안 나옵니다.
F=전체화면 재생, P=발표자 보기, Shift+P=청중 창 이중 발표. -->

---

## 왜 md-viewer?

- **런타임 외부 의존 0** — `git pull` + 실행만, 인터넷 불필요
- **다이어그램 4종 오프라인** — Mermaid · draw.io · D2 · PlantUML
- **Marp 발표** — 전체화면 · 발표자 뷰 · 청중 이중 창
- **Obsidian 호환** — 위키링크 · 백링크 · 그래프 뷰 · 전문 검색

<!-- 발표자 노트: 핵심 차별점은 "폐쇄망 자체완결". 빌드는 인터넷 PC에서,
실행은 폐쇄망에서 git pull 만으로. -->

---

## 발표 모드

- `F` — 전체화면 재생 (슬라이드 화면 꽉참)
- `P` — 발표자 보기 (현재 + 다음 + 노트 + 타이머)
- `Shift+P` — **청중 이중 창** (외부 모니터 전체화면 + 발표자 뷰)
- `←/→ · ↑/↓ · 휠` 네비, `B/W` 블랙·화이트, `G` 오버뷰
